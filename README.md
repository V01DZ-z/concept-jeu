## Le fun et le flow

- La source du fun pour le type de joueur visé (sans utiliser le mot *fun*) : De level up asser rapidement et de bien répartir ses points d'amélioration pour progresser 
- Le flow (équilibre défi / capacités) : Quand ton niveau monte les enemis son plus fort
- La rétroaction (son, lumière, animation) : Le tank du joueur, les pastilles et les enemis on chacun une couleur
- La rejouabilité (pourquoi recommencer) : recommencer pour tester d'autre tanks, débloquer des skins, et avoir un high score
